# Style audit

## Reference patterns
- Restrained academic navigation, clear page labels, and long-form reading flow.
- Generous white space, thin dividers, simple lists, and minimal visual interference.
- Team and publication content is text-led and optimized for scanning.
- Semantic page headings and explicit accessibility language establish a strong baseline.

## Original interpretation
- Cool neutral background, near-black text, and one electric-blue accent.
- A feedback-loop motif represents human, body, environment, and AI.
- Asymmetric typography, numbered sections, and editorial rows create a contemporary academic character.
- Portraits use consistent crops and no decorative stock imagery.
- Skip navigation, focus states, semantic headings, reduced-motion handling, contrast, and descriptive portrait text are built in.
