# Style audit

## Existing strengths

The original site established editorial typography, generous whitespace, clear route labels, thin rules, a warm neutral palette, and strong publication scanning. These qualities remain the foundation.

## Existing weaknesses and text density

The homepage relied on long statements and repeated rows with limited visual explanation. Research sections used the same placeholder orbit repeatedly. Team biographies were too prominent on overview surfaces, and mobile navigation lacked a dedicated disclosure control.

## Final system

- Typography: Manrope for clear reading, Newsreader italics for editorial inflection, and DM Mono for metadata.
- Color: warm paper, near-black green, muted sage, research blue, and a restrained coral feedback accent.
- Spacing: wide desktop gutters and 4–10rem section intervals; compact but readable mobile rhythm.
- Images: consistent 4:5 portrait crops, low saturation, no artificial faces.
- Motion: single-entry reveals and a slow, task-oriented 3D feedback loop; no auto-rotating camera.
- Layout: varied story compositions replace identical card grids.

## Preserved and changed

The five-route information architecture, academic restraint, portrait assets, and scan-friendly publications remain. The homepage is shorter and more visual; the research page now explains each system with a distinct accessible diagram.

## Accessibility

Semantic landmarks, skip navigation, focus visibility, mobile menu state, reduced-motion behavior, diagram labels, portrait alt text, and a static WebGL fallback are included.
